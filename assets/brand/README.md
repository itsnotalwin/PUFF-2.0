# PUFF 2.0 final brand kit

Monochrome artwork exported from the live site's original bud geometry and Pacifico-outline wordmark. No replacement illustration or font.

- [Master logos](master): four SVG masters plus four high-resolution PNGs, white on black and black on white, both full logo and standalone wordmark.
- [WhatsApp profile pictures](social/WhatsApp): four circle-safe 640 × 640 PNGs.
- [Social media exports](social): 40 PNGs for WhatsApp, Instagram, Threads, Facebook, X, LinkedIn, TikTok, Pinterest, YouTube, Stories, posts, and banners.
- [Complete downloadable ZIPs](archives): logo kit, WhatsApp avatars, and complete social kit.

The website's look and functionality must not be changed by asset export. PNG sizes are verified by the exporter.
Regenerate from source with npm ci, node scripts/extract-puff-art.mjs, then python scripts/export-puff-assets.py after installing Python dependencies.
