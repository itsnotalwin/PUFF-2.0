# Generated site assets

Contains reusable brand deliverables; `brand/` is the official PUFF logo/social kit. Logo and social image binaries are generated by the scripts in `scripts/`; don't hand-edit outputs or substitute fonts. No runtime website code imports this folder. See `brand/README.md` for file inventory. Verify downloaded PNGs and archives against the generator, and keep the final approved site unaffected.
