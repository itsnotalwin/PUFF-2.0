# Source-wide UI design

The site uses near-black ink, warm cream, big tracked display type, the official PUFF script identity and liquid/drip interactions. Layouts should accommodate narrow mobile and wide desktop screens without clipping the hero, menu cards or bag controls. Menu prices must stay aligned with the data catalogue, and motion must not obstruct touch input, keyboard focus or legibility.

Capture route: the published PUFF 2.0 homepage, with representative 390×844 mobile and 1440×900 desktop viewports. Updated 2026-10-29. Authentic screenshot files have not yet been captured in this environment, so visual QA is **incomplete**.
