# Shared component design

Controls must preserve the brand's original black-and-cream palette, outlined circular add/remove buttons, liquid motion and script wordmark. The bag drawer uses large reachable controls and maintains clear numeric totals. Menu cards and mixer additions should produce identical bag entries; saved bags must reflect current catalogue weights and prices. Keyboard focus, touch hit areas, responsive layout and reduced-motion usability remain acceptance targets.
